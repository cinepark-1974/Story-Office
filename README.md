# STORY OFFICE

BLUE JEANS PICTURES 창작 사무실. STORY ENGINE SYSTEM의 엔진 14개를 한 화면에서 보고 바로 엽니다.

- **OFFICE** — 사무실 그림. 직원(엔진)을 누르면 그 엔진의 Streamlit 앱이 열립니다.
- **SYSTEM** — 『스토리엔진시스템 설명서』와 짝을 이루는 성계 쇼룸. 엔진 행성들이 중심 구체 둘레를 천천히 돕니다.

- **기획 회의** — 버튼을 누르면 직원들이 실제로 일합니다.
  1. 소재 발굴 담당이 전 세계 뉴스·보고서·판결·제도·직업·기술·사건을 검색해 현실 소재 후보를 가져옵니다. 기존 영화·드라마는 찾지 않습니다.
  2. 발제 담당이 후보 하나로 허구의 아이디어 한 장을 씁니다.
  3. 욕망 · 로그라인·인물 · 구조 · 장르 · 고증 · 독창성 · 시장 담당이 엔진 prompt.py 기준으로 각자 검토합니다.
  4. 편성 담당이 Idea Engine 판정 규칙(GO / CONDITIONAL / NOGO)과 포맷 확신도로 배정을 권고합니다.
  - 모든 지적에는 근거(실제로 검색된 문서의 S번호, 또는 아이디어 문장 인용)가 붙고, 근거 없는 말은 판정에 쓰지 않습니다.
  - 검색이 필수인 직원이 검색하지 않으면 그 의견은 판정에서 빠집니다.

직원은 역할로 앉아 있고, 엔진은 직원이 쓰는 도구입니다.

## Streamlit Secrets (회의에 필요)

```
ANTHROPIC_API_KEY = "엔진들이 쓰는 키"
OFFICE_PASSWORD = "사무실 비밀번호"
```

둘 중 하나라도 없으면 회의 버튼이 열리지 않습니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `main.py` | 화면 전체 (Streamlit 시작 파일) |
| `engines.py` | 엔진 목록, 한 줄 설명, 앱 주소, 사무실 자리, 성계 궤도 — **엔진을 추가하거나 주소가 바뀌면 이 파일만 고칩니다** |
| `staff.py` | 직원 명단과 직무, 기획 회의 진행 — **직원의 일을 바꾸려면 ROLES 의 brief 를 고칩니다** |
| `office_docx.py` | 회의 결과 워드 파일 (1쪽 아이디어, 2쪽 회의록) |
| `system_view.py` | 성계 그림과 움직임. 맨 위 숫자 두 개가 한 바퀴 도는 시간(초) |
| `static/office.webp` | 사무실 그림 |
| `static/core.webp` | 성계 중심 구체 |

최근 수정일은 GitHub 공개 기록을 1시간마다 읽어 옵니다.
